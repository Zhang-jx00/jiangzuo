## 这一发里有什么

### E26：**把 E20 留下的"需人工细判"清零** —— 逐条判完最后几条，并收窄最后一种"规则过宽"。

- **起因**：E20 逐条判定 DVWA 结论区后，有 3 条被标成"需人工细判"（**单列，不混进分子也不混进分母**），
  目标是"先把没判的变成判过的"。E25 已经把其中 1 条变成真阳性（`JZ-UPLOAD-001` 收窄后剩下的
  `move_uploaded_file` 是真漏洞）；本轮把最后 2 条判完 ⇒ **未判定 = 0**。
- **那 2 条是什么**：DVWA `api/source/low.php:26` 与 `api/source/medium.php:14` 的
  `user_info.innerHTML = 'User details: ';` —— 读完整源码确认：**赋的是纯字符串常量**，
  没有把外部内容写进 DOM ⇒ **不该报**。而 `JZ-XSS-001` 是 `ignore_strings: true` 的
  **pattern 规则**（只看写法、不看污点）⇒ 只要出现 `.innerHTML =` 就报 ⇒ 属**规则过宽**。
- **修法**：sink 加一条负向先行，排除"赋纯字符串常量"这一形态。
  ⚠️ **能在掩码桶里判**是因为：字符串字面量被剥成 `''` ⇒「纯常量」= `innerHTML = '';`，
  而「常量 + 变量」= `innerHTML = '' + name;` ⇒ 两者可分。
  ⚠️ **必须把空格算进负向先行**：`(?!['"]["']\s*;)` 会被 `\s*` 的**回溯**绕过去
  （`\s*` 吃 0 个空格时负向先行看到 ` '';` ⇒ 通过）⇒ 我第一版就踩了，改成 `(?!\s*['"]["']\s*;)` 才成立。
- **误报率口径重述（分子分母同时变）**：硬误报 **1 / 62 ≈ 1.6%**（E25 是 3/64 ≈ 4.7% ⇒ **不可比**）。
- **判据**：`TestAuditXssConstantAssignment` **3 条**（纯常量不报 / 常量+变量仍报 / 纯变量仍报）。
- **变异校准 40/40 全红**（新增 1 条：让负向先行永远不成立 ⇒ 判据红）。
  ⚠️ 变异**不能**把整条 sink 换回老形态（老形态是新形态的**前缀** ⇒ 校准器会按
  "突变文本已存在 ⇒ 还原会连带改坏"直接 SKIP）⇒ 改成"在负向先行里多插一个字符"。
- **顺带做了两件收口**：
  1. **能力边界表补两条**（E25 挖到的机制事实，之前只在台账里）：
     「**『缺少 X』型规则写不成正向 pattern**」与「**规则默认在掩码桶上跑 ⇒ 看不见字符串内容**」。
  2. **两个停牌项定案**（用户授权我自行决定）：
     - **触发率 A 路线（无竞争对照）⇒ 不做**。它测的是"别的 skill 会不会抢上下文"，
       那不是本技能能控制的变量；历史上 7/24 的失败主因就是**加载竞争**，而"竞争"正是 A 路线的定义
       ⇒ 做了只会把"测不到"变成"测到还是不行"，**不改能力**；且要动 C 盘、装第三方 skill。
       ⇒ 改判为**决策（不做）**，不再是"待办"。
     - **发行渠道 ⇒ 做**：以 GitHub Release 形式发版（tag 已推、CI 全绿、release notes 齐备后发）。
- **零回退**：只改一条规则的 sink，**不动引擎** ⇒ flask/requests/自扫/覆盖/语料一字未变。

## 已知边界（不藏）

- 完整清单见 `references/audit-rule-authoring.md` 的「能力边界表」——
  **每条带"为什么做不到 + 代价 + 实测证据"，并用最小夹具钉住** ⇒ 引擎演进时测试会红、提醒改表。
- 三条最常被问到的：
  - **"没报"≠"安全"**：缺失型判据（暴力破解 / 验证码 / 速率限制）与跨请求、存储型数据流
    需要中间件 / 请求视角 ⇒ 静态扫描原理上拿不到，已交人工。
  - **规则默认在「掩码桶」上跑** ⇒ 看不见字符串内部（PHP < 5.5 的 `preg_replace('/x/e')` 当前检不出）。
  - **JS 里 `//` 的歧义**（注释 / 正则字面量 / 除法）⇒ 我们按注释处理，正则字面量同行之后的代码会被漏掉。

## 安装与使用

```bash
git clone https://github.com/Zhang-jx00/jiangzuo.git
# 复制到你的技能目录（Claude / ZCode / Codex / Cursor / Gemini CLI / OpenCode 通用）
cp -r jiangzuo ~/.claude/skills/          # 或 ~/.zcode/skills/、~/.agents/skills/
```

脚本**零依赖**（只用 Python 3.8+ 标准库）、**不联网**、**不改被扫项目**；
全项目审计链十步：索引 → 地图 → 粗筛 → 深挖 → 污点流 → 独立验证 → 分级 → 报告（MD/JSON/SARIF 2.1.0）→ 人工确认 → 续扫。

## 这一发里有什么（六轮，v0.55.0 → v0.60.0）

### v0.60.0 —— 把"需人工细判"清零

- `JZ-XSS-001` 的 `innerHTML` sink 加负向先行：**给 `innerHTML` 赋纯字符串常量不再报**
  （读 DVWA 源码确认那两条是常量，不是漏洞）；"常量 + 变量"与纯变量赋值**仍照报**。
- 能力边界表补两条：「『缺少 X』型规则写不成正向 pattern」「规则默认在掩码桶上跑 ⇒ 看不见字符串内容」。
- **停牌项定案**：触发率 A 路线 ⇒ **不做**（它测的是"别的 skill 会不会抢上下文"，那不是本技能能控制的变量，
  且历史上 7/24 的失败主因就是加载竞争 ⇒ 做了不改能力）；发行渠道 ⇒ **做**（即本文件）。

### v0.59.0 —— 修掉 E20 判定出的"规则过宽"硬误报

- `JZ-CODE-001`：去掉 `preg_replace`（PHP 5.5 起没有 `/e` 修饰符 ⇒ 不是动态代码执行）。
- `JZ-DEBUG-001`：去掉 `error_reporting(E_ALL)`（只设错误级别，本身不泄露；泄露的是 `display_errors=On`）。
- `JZ-UPLOAD-001`：去掉 content-type sink（`$_SERVER['CONTENT_TYPE']` 是请求头，不是上传限制）。

### v0.58.0 —— 变异校准器随技能一起分发

- `scripts/mut_calibrate.py` 入库（零依赖），新增 `--check-only`：**只核对锚点还准不准**（秒级、不跑测试）。
  CI 加一步跑它 ⇒ 锚点随实现演进而过期时**当场红**。
- `validate_skill.py` 新增**第 19 项**：校准器必须在库里 + 零依赖 + **CASES 条数从实物数出**，
  并与 CHANGELOG 最新条目对账 ⇒ "手抄的例数"当场红。

### v0.57.0 —— 性能护栏不许退回单次测量

- CI 的 bench 从 `--repeat 1` 改成 `--repeat 3` 且**取最快一次**。
  实测：单次读数极差 **20.6%** → repeat 3 取最快一次 **10.3%**
  （⚠️ 规划原本写"取均值"，实测**均值反而更抖**（11.6%）⇒ 改判为取最快一次）。

### v0.56.0 —— 能力边界文档化

- 分册新增「能力边界表」**5 条**（缺失型判据 / 净化点按 sink 上下文生效 / JS 里 `//` 的歧义 /
  跨请求与存储型数据流 / 鉴权越权），每条带**为什么做不到 + 代价 + 实测证据**，
  并用最小夹具钉住 ⇒ **"没报"≠"安全"**。

### v0.55.0 —— SARIF 过官方 SARIF 2.1.0 schema

- 把官方 schema 的「允许属性」白名单**硬编码**进零依赖自检（CI 跑的是等价自检）。

## 已知边界（不藏）

- **PHP < 5.5 的 `preg_replace('/x/e', …)`**（真的会执行代码）**当前检不出** ——
  规则默认在**掩码桶**（字符串字面量被剥掉）上匹配 ⇒ 看不见字符串里的 `/e` 修饰符。
- **JS 里 `//` 的歧义**（注释 / 正则字面量 / 除法）：我们按注释处理 ⇒ **正则字面量同行之后的代码会被漏掉**。
- **缺失型判据**（暴力破解 / 验证码 / 速率限制）与**跨请求、存储型数据流**（存储型 XSS）
  需要中间件 / 请求视角 ⇒ 静态扫描原理上拿不到，已交人工。
- **"缺少 X"型规则写不成正向 pattern**（否定判断）。
- 完整清单见 `references/audit-rule-authoring.md` 的「能力边界表」（每条带实测证据与最小夹具）。

## 安装与使用

```bash
git clone https://github.com/Zhang-jx00/jiangzuo.git
# 复制到你的技能目录（Claude / ZCode / Codex / Cursor / Gemini CLI / OpenCode 通用）
cp -r jiangzuo ~/.claude/skills/          # 或 ~/.zcode/skills/、~/.agents/skills/
```

脚本**零依赖**（只用 Python 3.8+ 标准库）、**不联网**、**不改被扫项目**；
全项目审计链十步：索引 → 地图 → 粗筛 → 深挖 → 污点流 → 独立验证 → 分级 → 报告（MD/JSON/SARIF 2.1.0）→ 人工确认 → 续扫。

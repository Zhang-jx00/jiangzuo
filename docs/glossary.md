# 将作术语表（完整版）

> SKILL.md 内联 6 个高频术语以保证行为一致；本文件是面向贡献者与维护者的完整版。
> 新增术语时：先在对应分册定义清楚，再同步本表；全文用词必须与本表一致。

| 术语 | 含义 |
|---|---|
| 核心循环 | 先读懂 → 再想清 → 后动手 → 必验证 → 留文档，五步顺序不可换 |
| 铁律 | 没有新鲜验证证据不得宣称完成；子代理/分包商产出同样要核验 |
| 分级门 | L0 咨询 / L1 小修 / L2 功能 / L3 项目 / L4 事故，先定级再干活 |
| 单向棘轮 | 执行中发现复杂度上升，流程级别只能升、不能降 |
| HARD-GATE | 触发即停：歧义、不可逆、新依赖、选型拍板、越界、调其他技能——先问再做 |
| 大白话复述 | 用用户视角的话复述目标、非目标、完成标准，请其确认 |
| 验收标准三件套 | 功能标准（EARS 句式）+ 边界异常 + 每条的验证方式 |
| 交接单 | 调用其他技能/子代理时交代：目标/上下文/期望产出/验收标准/禁区 |
| 常备授权 | 用户授权的"以后这类直接做"，记入 learnings.md，范围只有用户能改 |
| 交付报告四问 | 改了什么 / 为什么这么改 / 怎么验证的 / 还剩什么风险 |
| 兜底 | 首选方案不可用时的 B 计划——提议任何方案时必须先备好它 |
| learnings | 项目 `docs/jiangzuo/learnings.md`：教训与授权记录，同类任务开工先读 |
| 反合理化表 | "念头 → 必须执行的动作"对照表，用于对抗跳过纪律的借口 |
| 红旗信号 | 出现即停止的征兆清单，与反合理化表互补：一个防辩解、一个防状态 |
| 分册 | references/ 下按阶段读取的参考文件，引用保持一层深 |

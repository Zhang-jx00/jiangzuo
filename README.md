## 这是什么

**将作**不是代码片段合集，而是一套注入给 AI 编程助手的**工作方式**。它解决的问题是：AI 写代码很快，但没有工程师的纪律——不读代码就动手、需求模糊就开写、没验证就说"完成"、顺手改坏无关的东西。

加载将作后，AI 在任何软件项目里按一条不变的循环工作：

```
① 先读懂 → ② 再想清 → ③ 后动手 → ④ 必验证 → ⑤ 留文档
```

以及三条铁律：

- **没有新鲜验证证据，不得宣称完成**（"应该能跑"不算证据）
- **没有找到根因，不得动手修 bug**（禁止糊表象）
- **只做任务范围内的最小改动**（不擅自引依赖、不顺手重构）

## 任务分级门（防过度流程，也防跳步）

| 级别 | 场景 | 流程重量 |
|---|---|---|
| L0 | 咨询、评审（不改代码） | 读懂 → 给有出处的结论 |
| L1 | 小 bug、小调整 | 定位 → 最小修复 → 验证 |
| L2 | 新页面/接口/模块 | 澄清确认 → 小设计确认 → 逐任务 TDD → 审查 |
| L3 | 新项目、大重构 | 完整链路 + 文档落盘 |
| L4 | 线上事故 | 止血 → 恢复 → 根因 → 复盘 |

单向棘轮：执行中发现复杂度上升只能升级、不能降级。

## HARD-GATE：它会主动问你

需求有歧义、涉及不可逆操作、要引新依赖、界面效果需拍板——这些时刻将作**停止动手先提问**：用大白话一次最多问 3 个问题，每问给选项带推荐，然后用"我理解你要的是…不在范围内的是…做完的标准是…"复述确认后才开工。

## 安装

将作遵循 [Agent Skills 开放规范](https://agentskills.io)，任何兼容客户端（ZCode / Claude Code / Codex / Cursor / Gemini CLI / OpenCode 等）均可使用。

**方式一：复制到用户级技能目录**（全局生效）

```bash
# ZCode
git clone https://github.com/<you>/jiangzuo.git && cp -r jiangzuo ~/.zcode/skills/
# Claude Code
cp -r jiangzuo ~/.claude/skills/
```

**方式二：项目级**（仅当前项目生效，可随仓库提交给团队）

```bash
cp -r jiangzuo <你的项目>/.zcode/skills/     # 或 .claude/skills/
```

**方式三：skills.sh CLI**

```bash
npx skills add <you>/jiangzuo
```

安装后无需任何配置：当你提出任何与软件开发有关的需求（哪怕只是"帮我看看这个报错"），技能自动加载。

## 使用效果示例

**你说**："帮我做个搜索框"

**没有将作**：AI 直接写一个 `<input>` 加请求，搜索范围、排序、空结果全靠猜。

**有将作**：
> 动手前确认三件事：① 搜索范围：只搜商品标题（推荐，现有 `/api/items` 已支持 `?q=`）还是连详情一起搜？② 输入停顿 300ms 自动搜（推荐）还是回车触发？③ 空结果给"没找到+清空按钮"（推荐）？
> 我先按推荐项做，验收标准：输入"手机"出手机类商品、空结果有提示、清空恢复列表。对吗？

然后：摸底找现有组件 → 按契约 mock → 实现（四态齐全）→ 联调核对 → 测试 → preflight 自检 → 交付报告（改了什么/为什么/怎么验证/剩余风险）。

本技能的设计不是拍脑袋，来自一轮系统调研（155+ 篇来源、25 个高星仓库深析），**每条规则的出处可追溯**：见 [docs/research-notes.md](docs/research-notes.md) 的"结论 → 来源 → 落点"映射表。

- **Agent Skills 开放规范**（agentskills.io）：name/description 约束、<500 行、渐进式披露三层
- **Anthropic 官方最佳实践**：description=触发器公式、自由度三档、反模式清单
- **arXiv《Demystifying Agent Skills》**（8135 次实验）：技能价值 65.7% 来自"程序性锚定"——所以本技能的内核是流程与纪律，不是知识堆砌
- **obra/superpowers**（295k★）：铁律+反合理化表的纪律写法、单向棘轮、计划落盘
- **planning-with-files**（27k★）：文档落盘对抗长任务遗忘
- **GitHub spec-kit / Kiro**：EARS 式验收标准、门禁式流程
- **Snyk ToxicSkills**（3984 个技能审计）：技能供应链安全——本技能脚本零依赖、可审计、不联网
